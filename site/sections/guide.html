Install and sign in

Bamen currently targets 64-bit Windows and SketchUp 2025 Desktop. Install SketchUp first. The Bamen setup is designed to install both Desktop and the extension for your Windows account.

The public installer is pending release qualification. Public downloads will be listed on GitHub Releases.

Close SketchUp before running setup. Open Bamen from the Start menu and select Sign in with Google. The SketchUp HUD uses the same Bamen session on that Windows account.

Render your first panel

  1. Create an episode. In Bamen, select New Episode and save a .bmn project.
  2. Import an entire page. Drop the file in Pages or click Add pages. The importer accepts PNG, JPEG, WebP, and supported CLIP pages.
  3. Register a panel. Use Rectangle or Polygon to mark a panel. With the panel selected you can adjust its frame and rotation. Wait for Bamen to confirm the save.
  4. Open the storyboard in SketchUp. Use Open in SketchUp in Bamen, or browse to the saved project from the HUD. Select the page and panel, then frame the scene in Model mode.
  5. Capture and review. Press F6 and wait for Saved. Use F7 to recall a camera. If the HUD requests a model binding, finish that step before capturing.
  6. Render. Open the Render workspace. Click a page or panel card to add it to the selection. Pick your output settings, then select Render selected panels.

Shortcuts

R / P
Rectangle or polygon panel in Desktop
Space + drag
Pan the Desktop canvas
Z + left drag
Zoom in Desktop or SketchUp Storyboard mode
Alt + 1 / 2
Switch Model and Storyboard modes in SketchUp
F6 / F7
Capture or recall a camera in SketchUp

In the HUD, hover over the dim icon to adjust the background darkness. The storyboard page keeps its own opacity.

Uninstall

Close Bamen and SketchUp. Open Windows Settings → Apps → Installed apps → Bamen and choose Uninstall. Setup removes its Bamen application and SketchUp extension files. Keep your .bmn projects and source artwork wherever you saved them.
